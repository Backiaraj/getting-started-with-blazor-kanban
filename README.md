# Getting Started with the Blazor Kanban Component

A minimal Blazor sample demonstrating how to use the [Blazor Kanban](https://www.syncfusion.com/gantt-sdk/blazor-kanban-board) component in a Blazor Server application. The project includes examples for populating cards, enabling swimlanes, and basic board configuration.

## Overview

This sample shows the essential steps to integrate the [Blazor Kanban](https://www.syncfusion.com/gantt-sdk/blazor-kanban-board) component into a Blazor app, including data binding, swimlane setup, and initial card population. Use it as a starting point for building Kanban-driven UIs.

## Features

- Basic Kanban setup and configuration
- Card population and data binding
- Swimlane enablement and examples

## Getting Started

### Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

### Clone the Repository

```bash
git clone https://github.com/SyncfusionExamples/getting-started-with-blazor-kanban.git
cd getting-started-with-blazor-kanban
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
